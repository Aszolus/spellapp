# Historical Phase 1 Plan

This document is retained as historical context. It described the original prepared-caster workflow plan and is no longer the active product roadmap.

The current direction is documented in:

1. `README.md`
2. `requirements.md`
3. `technical-requirements.md`
4. `docs/CharacterCreation.md`
5. `docs/LevelingUp.md`

## Superseded Scope

The original Phase 1 scope focused on:

1. Prepared spellcaster profiles.
2. Spell slot preparation and casting.
3. Focus tracking.
4. Session log and undo.
5. Spell-centered character context.

Those features remain product goals, but they are no longer the first definition of the app. The builder foundation comes first.

## Current Replacement Direction

1. Complete level-one character creation against `docs/CharacterCreation.md`.
2. Put all post-level-one choices in the Level Workbench.
3. Make rules grants, validation, and derived facts visible and explainable.
4. Add spell preparation and casting on top of character-derived rules state once the builder model is stable.
