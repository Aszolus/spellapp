# Historical Phase 0 Plan

This document is retained as historical context. It described the original spell-first foundation work and is no longer the active product roadmap.

The current direction is documented in:

1. `README.md`
2. `requirements.md`
3. `technical-requirements.md`
4. `docs/CharacterCreation.md`
5. `docs/LevelingUp.md`

## Superseded Scope

The original Phase 0 scope focused on:

1. Android project scaffolding.
2. Offline build gates.
3. Local spell dataset ingestion.
4. Room-backed spell browsing.
5. Basic Compose navigation.

Those foundations still matter, but they now support a broader PF2e character builder and table companion.

## Current Replacement Direction

1. Keep runtime behavior fully offline.
2. Treat character creation and leveling as first-class workflows.
3. Keep spell browsing and spellcasting support as part of the complete character experience.
4. Derive visible character facts from selected build choices and local rules data.
